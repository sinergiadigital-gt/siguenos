Para probar:
1. Abra index.html en el navegador.

Para GitHub Pages:
1. Cree un repositorio llamado "siguenos".
2. Suba el contenido de esta carpeta a la raiz del repositorio.
3. En Settings > Pages seleccione Deploy from a branch.
4. Seleccione la rama main y carpeta /(root).
5. La URL quedara con el formato:
   https://sinergiadigital-gt.github.io/siguenos/
